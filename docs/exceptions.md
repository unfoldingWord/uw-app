# Exceptions

Every exception to rules 1 to 4 of [`AGENTS.md`](../AGENTS.md), written before the code, in the same commit
(rule 5). An exception without an entry here is a defect. Newest first.

A row here closes: it names the event that ends it. A standing amendment belongs in the rule it amends. On
2026-09-30 fourteen standing rows were folded into AGENTS.md rules 2 and section 7 and PRD DX-4, and twelve rows
whose conditions were met were closed (`docs/proposals/2026-09-30-fold-standing-exceptions.md`, issue #6).
