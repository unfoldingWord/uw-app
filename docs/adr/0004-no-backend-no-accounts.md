# No backend and no accounts

The app has no server of its own and no sign-in. Discovery and downloads come from Door43 directly, all user state lives on the device, and sharing is device to device. This is surprising for a 2026 app and is deliberate: the audience includes leaders in places where an account is a risk and a connection is rare, the vision promises "no account needed" on the first screen, and a backend would be a second system to design, secure and pay for that no requirement needs. Sync across a leader's devices is the feature this forgoes; if it is ever wanted, it must be designed so that the no-account path remains complete.
